# Activation
Use for every package discovery review.

## Procedure
Read recall_findings and package_summary for exact counts. Page graph_slice,
lookup_evidence and supporting_references, then inspect source_contracts. Retrieve
each citation before submitting Finding with role discovery.

Batch workflow_planning_contract overview, tasks, connections and parameters first.
Preserve actual scheduler evidence versus task timers and parameter-file scopes. Use
definitions and properties for session connection overrides. Cite returned canonical
owners, not hashes. Submit a typed finding before final prose within six model calls.
Unconfigured bindings stay execution unknowns; no production data is needed to propose
a logical graph. Do not turn missing notification settings into a global design blocker.

## Evidence and permitted recommendations
Retrieve planning invocations and package_migration_contract, then page exact returned
callers/children through related_workflow_id. Record literal resolution, wait mode,
dynamic/missing boundaries and tightly bound shared-data evidence. Recommend scope
expansion explicitly; do not alter selected-workflow authority or certify closure
from shared definitions or counts. Follow the shared evidence-to-deliverable contract.

Preserve repository/folder/definition identities, unresolved references, disabled
tasks and diagnostics. Use metadata-only UC tools if caller identity is injected;
otherwise propose questions, not live access. Connection
aliases do not establish physical bindings, driver compatibility or authorization.

Use graph_slice/lookup_evidence diagnostic relevance and exact unresolved node kind,
expected_kinds and status. In the UC-source scenario, source dummy data is already in
Unity Catalog. Historical Oracle CONNECTIONREFERENCE redactions are not source-table
or target-layer gaps and are non-blocking context. Bronze/silver/gold are destinations,
not source scenarios. Missing session/mapping definitions remain affected-scope evidence
gaps. Do not generalize UNRESOLVED.
Do not call a source unavailable because this analysis did not query Unity Catalog.
Use XML source/target repository, folder, database, owner, columns and captured query
evidence to choose catalog/schema/full table names. Equal names never decide bindings.
Read uc_metadata_state, page UC lists and inspect uc_get_table before record_uc_binding.
Only exact role-authorized canonical source/target IDs with owned evidence are bindable.
Observations are untrusted metadata; candidate schemas are not data or semantic proof.
Permission/provider failures remain unknown. Exact table-not-found is scoped only to
the qualified lookup. No binding is required for non-table tasks. Without a provider,
preserve the scenario assumption or explicit runtime parameters, not verified bindings.

## Unsupported cases and validation
Missing export metadata remains unknown. Never infer activity from enabled state.
Example: cite an unresolved reference and request a scoped export. Counterexample:
equal object names do not prove equal definitions or safe connectivity.
