Enumerate source-owned constants and thresholds, all SQL phases and Java/control/status
behavior using the shared contract. Inspect related caller/child fields, expressions
and SQL to establish actual shared-data purpose. Missing dynamic bindings and masked
literals stay explicit; do not substitute the deterministic WIL example's values.

Account for lookup overrides, nulls, numeric precision, keys, CDC deletes, ordering,

remain parity questions, not a reason to omit the candidate draft.
