    Planned

    dbt transformation target

    dbt manages SQL transformations as versioned models with dependency references, tests, and generated documentation. Databricks executes the SQL; dbt is not a storage engine.

    ORION could propose dbt models for suitable SQL transformations, while Lakeflow Jobs orchestrates dbt and other approved tasks. Imperative commands, CDC, transactions, and external side effects require separate handling.

    This integration is planned. Adapter compatibility, licensing, runtime support, and semantic parity need verification before use.

    Planned

    Provider routing and economical models

    Add an optional OpenRouter adapter and explicit per-role model routing. Compare smaller and open-weight models against migration-specific evaluations before assigning them to authoring or independent validation.

    Route bounded extraction to economical models only when tests support it. Escalate difficult semantics explicitly; show measured token usage, latency, failures, and provider cost when available.

    External providers introduce new data-egress and credential requirements. Databricks OBO does not automatically authorize OpenRouter. No silent provider fallback.

    Required MVP work remains

    Reviewed artifacts and controlled delivery

    1. Approve a versioned redesign and its behavior coverage.
    2. Generate notebooks, SQL/Python libraries, tests, and a validated Declarative Automation Bundle.
    3. Review artifact hashes and independent test results.
    4. Publish to an authorized GitHub repository when supplied, with environment approvals.
    5. Deploy unscheduled jobs to the selected workspace. Scheduling and execution need separate user decisions.

    A DAB defines deployable resources and code paths. Uploading YAML alone is not a working transformation. This page does not enable generation, deployment, or GitHub publication.

    Partially implemented

    Reviewed memory and skills

    Architecture knowledge can be retrieved with evidence for review when configured. Hosted availability must be confirmed for your workspace. Consolidating rejected designs and automatically promoting skills are planned capabilities.

    Promote lessons into reusable skills only after review and regression checks. Evaluate memory retrieval before considering LoRA or other fine-tuning. Never train on credentials or customer content without explicit authorization.
